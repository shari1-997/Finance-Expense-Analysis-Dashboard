# Contributing

This repository is primarily a portfolio project.

If you want to suggest an improvement:

1. Open an issue describing the proposed change.
2. Explain why the change would improve the analysis or usability.
3. For workbook changes, validate formulas, PivotTables, slicers, and dashboard visuals.
4. Update the documentation when the workbook structure or methodology changes.
5. Submit a pull request with a concise description of the changes.
